# On-screen keyboard art

There is none: every keyboard is DRAWN, by `packages/ui/keyboard`.

The 48K's forty rubber keys, the ZX Spectrum+ / 128K toastrack's fifty-eight
and the ZX Spectrum Next's were each transcribed from a reference — the Next
and the Spectrum+ from photographs of both machines taken by the project
owner, the 48K from the key art that used to live in this directory (43 PNGs,
1.1 MB, one per key, descended from JSSpeccy3). Every key rectangle, every
legend, the shape of each moulding and the colours came off those; drawing
rather than compositing keeps the legends crisp at any size, lets all three
keyboards share one box, and leaves nothing to download.

The keys a game names with the "k" query parameter are drawn the same way, as
the 48K's rubber keys in whatever rows it asked for.
